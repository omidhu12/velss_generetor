# app

Start command: `node start.js`

Environment variables (all optional):

| Name | Meaning |
|------|---------|
| `SECRET` | Long random string. Keeps the same link after restarts/redeploys. |
| `PUBLIC_HOST` | Address or domain used in the printed link. |
| `PORT` | Port to listen on (usually set by the platform). |

The link is printed in the app logs on startup.
